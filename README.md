# 你的一天 · A Day with Short Bowel Syndrome

> 一个约 6 分钟的互动科普。你扮演一位短肠综合征患者，从早上六点四十到深夜十一点半，做完 9 个真实的决定。

**[→ 在线体验](https://austinxie-0304.github.io/A-Day-with-Short-Bowel-Syndrome/)**

---

## 这是什么

短肠综合征（Short Bowel Syndrome, SBS）是各种原因导致小肠广泛切除后，剩余肠道吸收面积不足以维持营养与水分平衡的慢性肠衰竭状态。

这个作品不解释病理，也不展示病房。它只做一件事：**把患者的一天，交给一个健康人过一遍。**

你会遇到 9 个时间点。每个时间点都有一个必须当场做出的决定——吃什么、什么时候吃药、这杯水怎么喝、洗澡先做哪一步。每个决定之后，屏幕上会并排出现两栏：

| | 普通人 | 你 |
|---|---|---|
| 喝水 | 接一杯，仰头喝完。五秒。 | 分三次，看表，每次 100 ml，判断这口该喝补液盐还是白水。 |

这就是全部的观点。

## 怎么玩

| 时间 | 场景 | 交互 |
|---|---|---|
| 06:40 | 睁眼之后的第一件事 | 单选 |
| 07:15 | 一片药，要提前四十分钟 | 单选 |
| 07:50 | 从七样里，挑三样 | 多选（限选 3） |
| 08:40 | 桌上那杯水，你看了三十秒 | 单选 |
| 10:40 | 「给你也带了一杯」 | 单选 |
| 12:30 | 「米饭要多少？」 | 滑块 |
| 15:20 | 配一袋补液盐 | 分组配方 |
| 20:00 | 洗澡，要先做四件事 | 顺序排序 |
| 23:30 | 凌晨两点十七分 | 单选 |

全程有三条指标在跑（水合状态 / 能量 / 舒适度），以及一个只增不减的计数器：**今天花在「管理疾病」上的分钟数**。

走完之后是一张账单，以及一张「同一件事，两个人」的对比表。

## 设计上的三个选择

**1. 对照是强制的，不是可选的。**
不管选对选错，反馈里一定有「普通人 vs 你」两栏。选错时会额外揭示正确做法，但对照组永远在——因为要传达的不是知识点，是**注意力的去向**。

**2. 判定分三档，不是对错二分。**

- 绿：更接近真实的做法
- 琥珀：可以理解，但代价不小（例如「直接说『我不能喝』」——诚实没错，但每次社交都变成一次自我暴露）
- 红：会让你下午更难

疾病管理里大量的真实困境，不在「对」和「错」之间。

**3. 用时间计费，而不是用分数。**
结算页最先出现的是一个很大的数字：你今天为「让身体正常运转」亲手花掉了多少分钟。同一批事，普通人约 20 分钟。

## 医学内容

涉及的操作细节按通行临床实践书写，包括但不限于：

- 洛哌丁胺餐前 30–60 分钟服用
- 口服补液盐一袋兑 250 ml 温水，不加糖、不加盐，依靠钠-葡萄糖协同转运吸收
- 成人剩余小肠 < 200 cm 可能出现短肠综合征，< 100 cm 多需长期肠外营养
- 替度鲁肽（teduglutide）为 GLP-2 类似物，用于促进肠道黏膜适应
- 中心静脉导管相关血流感染（CRBSI）的防护要点
- 少量多餐（每日 6–8 餐）、低脂低纤维低渗、限制草酸盐

> **免责声明**：本项目为科普互动演示，用于帮助公众理解短肠综合征患者的日常管理负担，**不构成任何医疗建议**。具体饮食、用药与导管护理方案须遵循主治医师与营养支持团队的个体化指导。文中的排便次数、补液量等数值为典型情境示意，个体差异较大。
